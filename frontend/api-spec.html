1. 概述

EACOswap 后端采用 Node.js + Express 构建，作为 Solana 数据提供商（CoinGecko / Helius / Birdeye / Jupiter）的安全代理层。 API Key 仅存储于服务端环境变量，前端绝不暴露。

Base URL

http://localhost:3000/api

Content-Type

application/json

响应格式

JSON (统一封装)

CORS

可配置 (默认 *)

2. 统一响应格式

所有 API 返回统一结构：前端必须读取 data.data 或 data 字段，不能直接取根级数据。

成功响应

{
"success": true,
"data": { ... } // 具体业务数据
}

失败响应

{
"success": false,
"error": "错误描述信息"
}

6. 安全规范

API Key 管理：Helius / Birdeye Key 仅存在于后端 .env，禁止暴露给前端。

  • CORS：生产环境配置 CORS_ORIGINS 为具体域名，禁用 *
  • Rate Limit：默认 60 req/min，生产可按需调整
  • Helmet：启用 CSP、XSS 过滤、HSTS 等安全头
  • 超时控制：所有上游请求 15 秒超时，防止挂起
  • 缓存策略：价格 60s、市值 300s、报价 15s、资产 120s
  • 错误脱敏：生产环境不暴露内部错误详情

9. API 设计哲学

9.1 统一封装原则

  • 屏蔽差异：前端不关心数据来自 CoinGecko 还是 Birdeye，只调用 /api/birdeye/price，后端自动降级
  • 统一格式：所有响应包装为 { success, data, error }，前端处理逻辑一致
  • 安全代理：API Key 仅在后端，前端不暴露任何第三方凭证
  • 缓存层：高频数据（价格）缓存 30-60s，低频数据（市值）缓存 5 分钟

9.2 分层架构

// | 前端 (Web/Android/iOS/Telegram) |

// +---------------------+---------------------+
// | HTTP + API Key

// v v v
// CoinGecko Helius Birdeye

12.2 RPC 调用注意事项

关键警告：如果 getBlock / getTransaction / getTransactionsForAddress 未设置 maxSupportedTransactionVersion: 1，当区块中包含任意 v1 交易时，整个调用会失败（所有交易都不会返回）。

// 正确：请求时声明支持 v1
const block = await connection.getBlock(slot, {
  maxSupportedTransactionVersion: 1,
});

// 错误：未声明版本，遇到 v1 交易时整块失败
const block = await connection.getBlock(slot); // ❌ 可能返回 null
