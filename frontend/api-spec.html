1. 概述

EACOswap 后端采用 Node.js + Express 构建，作为 Solana 数据提供商（CoinGecko / Helius / Birdeye / Jupiter）的安全代理层。 API Key 仅存储于服务端环境变量，前端绝不暴露。

Base URL

http://localhost:3000/api

Content-Type

application/json

响应格式

JSON (统一封装)

CORS

可配置 (默认 *)

2. 统一响应格式

所有 API 返回统一结构：前端必须读取 data.data 或 data 字段，不能直接取根级数据。

成功响应

{
"success": true,
"data": { ... } // 具体业务数据
}

失败响应

{
"success": false,
"error": "错误描述信息"
}

4. API 端点

GET /api/health
健康检查 — 返回服务状态及依赖服务可用性

响应

{
"status": "ok",
"timestamp": "2026-09-08T13:33:46.000Z",
"services": {
"coingecko": true,
"helius": true, // 是否配置了 HELIUS_API_KEY
"birdeye": false, // 是否配置了 BIRDEYE_API_KEY
"jupiter": true
},
"uptime": 3600
}
GET /api/config
服务端配置信息 — 安全暴露，不含实际 Key
{
"heliusConfigured": true,
"birdeyeConfigured": false,
"cacheTtl": 60,
"version": "1.0.0"
}

POST /api/helius/rpc
Helius RPC 代理 — 转发 Solana JSON-RPC 请求（需 HELIUS_API_KEY）

请求体

{
"jsonrpc": "2.0",
"id": 1,
"method": "getBalance",
"params": ["DqfoyZH96RnvZusSp3Cdncjpyp3C74ZmJzGhjmHnDHRH"]
}

响应

{
"success": true,
"data": {
"jsonrpc": "2.0",
"id": 1,
"result": {
"value": 1000000000
}
}
}

未配置 HELIUS_API_KEY 时返回 503 { success: false, error: "Helius API not configured" }

GET /api/helius/das/assets-by-owner
查询指定钱包地址的代币资产列表 — Helius DAS API（需 HELIUS_API_KEY）

请求参数

参数类型必填说明
ownerstring是Solana 钱包地址 (Base58)

缓存 2 分钟，适合频繁刷新的资产面板

GET /api/helius/token-accounts
查询代币持有者数量 — 通过 getProgramAccounts 统计（需 HELIUS_API_KEY）

请求参数

参数类型必填说明
mintstring是代币合约地址

响应

{
"success": true,
"data": {
"jsonrpc": "2.0",
"result": [...],
"holderCount": 15234 // 后端自动统计
}
}
GET /api/birdeye/token/:address
Birdeye 代币详情 — 深度数据、社交媒体、标签（需 BIRDEYE_API_KEY）

路径参数

参数类型必填说明
addressstring是代币合约地址

未配置 BIRDEYE_API_KEY 时返回 503

GET /api/birdeye/price/:address
代币实时价格 — 优先 Birdeye，无 Key 时自动降级到 CoinGecko

路径参数

参数类型必填说明
addressstring是代币合约地址

降级策略

  1. 若配置了 BIRDEYE_KEY，优先调用 Birdeye API（缓存 30 秒）
  2. 若 Birdeye 失败或无 Key，自动降级到 CoinGecko token_price
  3. CoinGecko 缓存 60 秒
GET /api/jupiter/quote
Jupiter v6 兑换报价 — 最优路径、滑点、价格影响（免费，缓存 15 秒）

请求参数

参数类型必填默认值说明
inputMintstring否SOL输入代币合约地址
outputMintstring是—输出代币合约地址
amountnumber是—输入数量（lamports / raw units）

响应

{
"success": true,
"data": {
"inputMint": "So11111111111111111111111111111111111111112",
"outputMint": "DqfoyZH96RnvZusSp3Cdncjpyp3C74ZmJzGhjmHnDHRH",
"outAmount": "1000000000", // 输出数量 (raw)
"outAmountWithSlippage": "995000000", // 含滑点输出
"priceImpactPct": "0.25", // 价格影响 %
"routePlan": [...], // 路由步骤
"swapMode": "ExactIn",
"slippageBps": 50 // 滑点基点 (0.5%)
}
}

报价有效期极短（约 15 秒），获取后需立即执行交易。仅预览路由，实际兑换需调用 Jupiter API 获取 transaction。

5. 错误码

HTTP 状态场景示例
200请求成功{ success: true, data: {...} }
400参数缺失/无效{ success: false, error: "Missing outputMint parameter" }
503上游服务未配置{ success: false, error: "Helius API not configured" }
404API 端点不存在{ success: false, error: "API endpoint not found" }
429速率限制触发{ success: false, error: "Too many requests" }
500服务器内部错误{ success: false, error: "Internal server error" }

6. 安全规范

API Key 管理：Helius / Birdeye Key 仅存在于后端 .env，禁止暴露给前端。

  • CORS：生产环境配置 CORS_ORIGINS 为具体域名，禁用 *
  • Rate Limit：默认 60 req/min，生产可按需调整
  • Helmet：启用 CSP、XSS 过滤、HSTS 等安全头
  • 超时控制：所有上游请求 15 秒超时，防止挂起
  • 缓存策略：价格 60s、市值 300s、报价 15s、资产 120s
  • 错误脱敏：生产环境不暴露内部错误详情

7. 请求示例

获取 SOL 价格

// cURL
curl -X GET http://localhost:3000/api/sol-price

// JavaScript (fetch)
const res = await fetch('/api/sol-price');
const data = await res.json();
console.log(data.data.solana.usd); // 145.32

获取代币市值排行 (Top 100)

// cURL
curl -X GET "http://localhost:3000/api/tokens/market-cap?per_page=100&page=1&vs_currency=usd"

// JavaScript
const res = await fetch('/api/tokens/market-cap?per_page=100');
const { data } = await res.json(); // data = 代币数组

Jupiter 兑换报价 (SOL → EACO)

// 输入 1 SOL = 1,000,000,000 lamports
curl -X GET "http://localhost:3000/api/jupiter/quote?inputMint=So11111111111111111111111111111111111111112&outputMint=DqfoyZH96RnvZusSp3Cdncjpyp3C74ZmJzGhjmHnDHRH&amount=1000000000"

// JavaScript
const params = new URLSearchParams({
inputMint: 'So11111111111111111111111111111111111111112',
outputMint: 'DqfoyZH96RnvZusSp3Cdncjpyp3C74ZmJzGhjmHnDHRH',
amount: '1000000000'
});
const res = await fetch(`/api/jupiter/quote?${params}`);
const { data } = await res.json();

查询代币持有者数量

// EACO 持有者数量
curl -X GET "http://localhost:3000/api/helius/token-accounts?mint=DqfoyZH96RnvZusSp3Cdncjpyp3C74ZmJzGhjmHnDHRH"

Helius RPC 代理 (获取余额)

// POST body
curl -X POST http://localhost:3000/api/helius/rpc \
-H "Content-Type: application/json" \
-d '{"jsonrpc":"2.0","id":1,"method":"getBalance","params":["WalletAddress"]}'
